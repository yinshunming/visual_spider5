# 可视化网页采集产品规格

## 1. 文档目的

本文定义 `visual_spider5` 首版的用户、核心流程、功能边界、容量约束与验收标准。领域词汇以根目录的 [`CONTEXT.md`](../CONTEXT.md) 为准，架构实现见 [`architecture.md`](./architecture.md)，交付顺序见 [`roadmap.md`](./roadmap.md)。

## 2. 产品定位

`visual_spider5` 是面向小团队私有部署的零安装 Web 可视化网页采集工具。采集人员通过服务器提供的远程 Chromium 页面点选目标元素，保存采集任务，手动执行采集运行，并预览或导出结构化结果。

首要用户是懂基本网页结构和数据概念、但不希望编写爬虫代码的数据运营或分析人员。首版不面向公共 SaaS、多组织协作或专业反爬开发场景。

## 3. 成功标准

首版完成时，一名新采集人员应能在不安装客户端或浏览器扩展、不编写代码的情况下完成以下工作：

1. 登录私有部署的 Web 应用。
2. 创建单页采集或列表采集任务。
3. 在远程页面中点选字段，预览并校验结果。
4. 保存任务并手动启动一次采集运行。
5. 查看运行进度、错误和结果记录。
6. 下载 CSV 或 JSON。

首版还必须满足：运行之间状态隔离、应用重启后状态可解释、结果按保留策略清理、危险目标地址被拒绝、Windows 与 Linux 均可直接运行。

## 4. 用户与权限

### 4.1 管理员

- 创建、停用账号并重置密码。
- 调整全局容量和结果保留期限。
- 查看和处理全部采集任务、采集运行、日志与结果。
- 首次启动时由配置创建初始管理员。

### 4.2 采集人员

- 只能创建、编辑、运行和查看自己的任务、运行与结果。
- 不能查看其他采集人员的数据。

首版不支持公开注册、邮箱验证、找回密码、多因素认证、自定义角色、任务共享或协同编辑。

## 5. 核心采集模式

### 5.1 单页采集

单页采集任务保存一个固定的公开网页 URL。每次运行重新访问该 URL，并将整个页面提取为一条结果记录。

- 不依赖列表、翻页或页面间跳转。
- 修改 URL 后任务重新进入草稿状态。
- 不支持运行时 URL 参数或批量 URL 导入。

### 5.2 列表采集

列表采集从包含重复数据项的网页开始：

1. 采集人员点选一个代表性列表项。
2. 系统根据 DOM 层级和同级结构推断重复项。
3. 页面高亮全部候选项并展示匹配数量。
4. 采集人员调整并确认列表项范围。
5. 字段相对于列表项定义。

一个列表项生成一条结果记录。首版支持以下导航：

- 重复点击“下一页”元素。
- 重复点击“加载更多”元素。
- 从列表项中的明确 URL 进入一层内容页，并把内容页字段合并到同一条结果记录。

首版不支持纯无限滚动、必须通过复杂点击才能得到的内容页 URL、多级内容页、表单驱动导航或自定义导航脚本。

## 6. 可视化配置

### 6.1 远程页面

- 目标网页在服务器隔离的 Chromium `BrowserContext` 中加载。
- 固定桌面视口为 `1280 × 720`；前端可等比缩放，输入坐标必须映射回远程视口。
- 只支持桌面鼠标和键盘交互，不支持移动设备、触摸或自定义设备模拟。
- 顶部显示地址栏、前进、后退和刷新操作。
- 弹出窗口统一纳入当前远程会话，不提供多标签管理。
- 禁止文件上传、页面下载、摄像头、麦克风、定位和系统通知权限。

配置会话规则：

- 每名用户同时最多 1 个配置会话。
- 无操作 15 分钟自动关闭，单次最长 2 小时。
- 任务配置持续自动保存。
- 重新打开任务时恢复 URL 和规则，但不恢复临时 Cookie、缓存或页面交互状态。
- 配置会话与正式采集运行不共享浏览器上下文。

### 6.2 浏览与选择模式

- 浏览模式允许点击、输入、滚动、前进、后退和刷新。
- 选择模式在悬停时高亮 DOM 元素；点击只选择元素，不触发原页面动作。
- 默认由系统生成元素定位规则。
- 高级设置允许手写 CSS Selector 或 XPath，并实时校验语法、匹配数量和高亮结果。
- 列表项、采集字段、内容页入口和翻页操作共用同一种元素定位规则模型。
- 不支持用户自定义 JavaScript。

### 6.3 采集字段

支持的字段来源：

- 元素可见文本。
- 元素属性，包括 `href`、`src` 和 `data-*`。
- 链接 URL 和图片 URL；相对地址补全为绝对地址。
- 当前页面 URL。

支持的最小清洗能力：

- 默认去除首尾空白，可选择保留原始空白。
- 可用正则表达式提取一个目标片段。
- 字段结果类型为文本、数字或 URL。
- 类型转换失败记录字段错误。
- 字段缺失保存为空值，不自动填入默认值。
- 预览同时展示原始值和最终值。

一条结果记录只包含扁平单值字段。字段规则匹配多个元素时，预览要求采集人员缩小范围；首版不支持数组字段、嵌套对象、一对多子表、跨字段公式、日期解析或复杂清洗流水线。

## 7. 任务、预览与运行

### 7.1 任务状态

- **草稿**：允许保存不完整或校验失败的配置，不能执行。
- **可运行**：入口、采集模式、必要定位规则、至少一个字段和执行限制全部校验通过。

编辑导致校验失效时，任务回到草稿。首版不提供发布、审批、完整版本历史、差异比较或回滚。

### 7.2 预览

- 单页采集预览当前页面产生的 1 条结果记录。
- 列表采集预览当前列表页最多前 20 条结果记录。
- 配置内容页字段时，只访问前 3 个内容页进行验证，其余记录显示为未预览。
- 预览与正式运行共用提取逻辑，但不创建采集运行，也不写入正式结果。
- 预览展示匹配数量、字段缺失和类型转换错误。

### 7.3 运行状态

采集运行状态包括：

- 等待
- 运行中
- 成功
- 部分成功
- 失败
- 已取消
- 已中断

运行启动时固化任务快照。之后编辑采集任务不影响已经排队或运行中的任务；运行详情能够查看当时使用的快照。

### 7.4 页面就绪与失败处理

- 导航先等待 `DOMContentLoaded`。
- 随后等待列表项或必要字段出现，默认超时 15 秒。
- 可配置元素出现后的额外等待时间，范围 0–5 秒，默认 0 秒。
- 单个页面失败后自动重试 2 次，总尝试次数最多 3 次。
- 重试仍失败时，记录 URL、失败阶段和错误原因，然后继续后续页面。
- 入口页打不开或浏览器无法启动时，整个运行失败。
- 有成功记录也有页面失败时，运行标记为部分成功。
- 用户可以取消运行；已经持久化的结果继续保留。

应用关闭或异常退出时，遗留的等待/运行中记录在下次启动后标记为已中断。已写入结果允许导出，首版不做断点续跑。

### 7.5 运行进度

正式运行不传输实时浏览器画面，只展示：

- 状态和执行阶段。
- 已访问页面数、原始记录数、去重数、最终记录数和失败数。
- 当前处理 URL。
- 最近结构化日志和错误。
- 已耗时、剩余容量与取消操作。

## 8. 结果、去重与导出

- 每条结果记录以 PostgreSQL `JSONB` 行保存，并关联采集运行。
- 结果通过服务器分页查询，前端不得一次加载全部记录。
- 可在单次运行内选择一个或多个字段作为唯一键。
- 唯一键完整且重复时保留第一条；唯一键包含空值时不判重。
- 首版不跨运行去重，也不维护历史增量数据集。
- 下载时流式生成 CSV 或 JSON，不长期保存重复导出文件。
- 采集任务长期保留，直到用户主动删除。
- 运行、结果和运行日志默认保留 30 天；管理员可调整全局天数。
- 到期清理为永久删除，不提供回收站或恢复。
- 远程页面帧和截图不持久化。

## 9. 容量与停止条件

单个私有部署的首版容量目标：

- 约 10 个账号。
- 全系统最多同时执行 3 个采集运行。
- 每名用户最多同时执行 1 个采集运行。
- 单次运行最多访问 200 个页面。
- 单次运行最多生成 10,000 条结果记录。
- 单次运行最长 30 分钟。
- 同一目标域名并发为 1，请求间隔至少 1 秒。

任一任务限制或系统硬限制达到后停止继续采集，并在运行详情中记录停止原因。首版不提供分布式执行、自动扩容、定时调度或消息队列。

## 10. 支持的目标网页

支持：

- 服务器可直接访问的公开 HTTP/HTTPS 页面。
- 服务端返回 HTML 的页面。
- JavaScript 动态渲染的普通 DOM 页面。

不支持：

- 需要登录或复用配置会话 Cookie 的页面。
- 验证码绕过、复杂反爬对抗、代理池或地区访问代理。
- 跨域 `iframe` 内部元素、Shadow DOM 和浏览器插件页面。
- 文件协议、FTP、`data:` URL 或服务器本地文件。

系统不读取或执行目标网站的 `robots.txt`，也不增加运行前权限确认步骤。浏览器使用当前 Chromium 的标准 User-Agent；不实现 User-Agent 轮换、设备指纹伪造、自动化特征隐藏或其他反检测能力。遇到 `429`、持续 `403` 或验证码时退避并停止。

该产品决策不代表对任何目标网站采集权限或数据使用权限的判断，部署者自行承担目标选择与数据用途责任。

## 11. 网络与认证安全

- 入口 URL、每次重定向和 DNS 解析结果都必须校验。
- 只允许 `http://` 和 `https://`。
- 禁止回环、私有网段、链路本地地址、云元数据地址及其他非公网目标。
- 防止通过重定向和 DNS 重绑定访问服务器内网。
- 使用 Spring Security 的服务端会话 Cookie，不使用 JWT 或浏览器 `localStorage`。
- 密码使用 BCrypt 哈希保存，启用 CSRF 防护。
- Cookie 使用 `HttpOnly` 和合适的 `SameSite` 策略。

首版由 Spring Boot 直接提供 HTTP，不内置 HTTPS 或证书管理。系统只能部署在可信局域网或 VPN 内，不得直接暴露到公网；HTTP 下无法获得传输加密，也无法启用 `Secure` Cookie。

## 12. 首版明确不做

- 桌面客户端或浏览器扩展。
- 节点画布、任意流程编排、条件分支或用户脚本。
- 公共注册、多组织 SaaS、计费、套餐和任务协作。
- 目标网站登录态、验证码识别、代理池和反检测。
- 定时调度、断点续跑和跨运行增量采集。
- 批量 URL 输入、纯无限滚动、多级内容页。
- 数组、嵌套结果、一对多子表和复杂数据转换。
- 移动设备模拟、文件上传下载和运行画面直播。
- 内置 HTTPS、Docker、Nginx、Redis、消息队列、Elasticsearch 或对象存储。

## 13. 首版验收清单

- 管理员可以创建账号，采集人员之间的数据不可互相访问。
- 单页采集完整链路可在 Windows 和 Linux 上运行。
- 列表采集能识别重复项、翻页/加载更多并进入一层内容页。
- 系统生成与手写 CSS/XPath 均能预览、校验和高亮。
- 正式运行能够排队、取消、重试、部分成功和处理中断。
- 运行使用任务快照，编辑当前任务不改变历史结果含义。
- 结果能够分页、运行内去重并流式导出 CSV/JSON。
- 并发、页面数、记录数、时长、会话和保留期限限制生效。
- SSRF 防护能够拒绝直接、重定向和 DNS 变化后的内网目标。
- 应用重启后遗留运行标记为已中断，已写入结果仍可访问。
- 部署文档明确 HTTP 使用限制、安装步骤、日志位置和升级方式。
